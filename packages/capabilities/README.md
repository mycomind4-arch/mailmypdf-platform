# @mailmypdf/capabilities

Shared, provider-neutral capability primitives promoted from the MailMyPDF ecosystem.

This package intentionally contains contracts and small deterministic utilities. Provider implementations, credentials, persistence, and vertical-specific policy stay outside the package.

## Included

- provenance and verified facts
- document integrity
- redaction
- rate limiting
- consequential-action approvals
- case/correspondence records
- evidence sets
- timelines and deadlines
- contradiction detection
- quality reports
- explainability
- policy evaluation
- AI evaluation cases
- federated search contracts
- document-photo preprocessing contracts
- agent runtime contracts
- vertical manifests
