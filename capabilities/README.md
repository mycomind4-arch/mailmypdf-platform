# Ecosystem Capability Harvest

This directory contains reusable technology promoted from sibling repositories.

Promotion rules:
- copy/adapt only technology with a reusable boundary;
- preserve provenance to the source repository and file;
- keep domain-specific rules in their vertical;
- add tests/fixtures before broad consumption;
- never copy secrets, tenant data, or credentials.

Harvested sources in this batch:
- FairProcess: provenance/case-model patterns and deterministic policy boundary.
- Ruth Solv Flow: Cloudflare Workers AI provider adapter pattern.
- MailMyPDF: fulfillment/product capability inventory (implementation remains canonical in MailMyPDF).
