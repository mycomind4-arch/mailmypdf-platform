# Import Boundaries

## Promote into Platform

Generic algorithms, contracts, schemas, safety boundaries, evaluation harnesses, and provider adapters.

## Do not copy

- vertical UI
- vertical prompts
- jurisdiction-specific rules
- agency-specific policy
- product-specific pricing
- MailMyPDF identity/billing/fulfillment implementation

## Canonical ownership

MailMyPDF owns identity, accounts, organizations, billing, payments, fulfillment, mailing, tracking, and production proof. Platform consumes stable contracts.

## Candidate technology requires a second-use test

A candidate should not become a Platform dependency until at least two verticals can consume it or the capability is clearly foundational infrastructure.
